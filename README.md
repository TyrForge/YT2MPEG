The simplest app to download MP3 or MP4 files utilizing Yt_dlp

# Installation
 1. Install FFMPEG (Win 11)
 just open powershell with admin privliges and run command <br>
``` winget install -e --id Gyan.FFmpeg ```

2. Install Python and add it to path and run <br> ``` RUN.bat ```

# Requirements
 * FFMPEG
 * Python 3.10+ (preferrably 3.14.x)
